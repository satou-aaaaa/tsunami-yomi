# 津波よみ（tsunami-yomi）

予想される津波の高さを見て、どの発表になるか（津波予報・津波注意報・津波警報・大津波警報）を当てる1日5問の学習ゲーム。正解したらとるべき行動も選ぶ。津波情報のことば（観測中・到達予想時刻・遡上高）や津波のしくみ（速さ・第一波）の問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/tsunami-yomi/>

- 中身は気象庁の津波のページ（「津波警報・注意報、津波情報、津波予報について」<https://www.jma.go.jp/jma/kishou/know/jishin/joho/tsunamiinfo.html>・「よくある質問集 津波について」・「津波発生と伝播のしくみ」）に書いてあることだけです。
- 問題に出る津波の高さは練習のための例で、本物の津波ではありません。
- このゲームは防災の助言や、公式の情報の代わりではありません。津波の情報は気象庁で確かめてください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
